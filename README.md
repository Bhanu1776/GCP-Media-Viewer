# GCP Media Viewer 🎥🌐

## Overview

The GCP Media Viewer is a modern web application built using Next.js 15 and Shadcn UI. It allows users to input specific segments of Google Cloud Platform (GCP) storage URLs to view documents, images, and videos seamlessly. The application features a sleek, responsive design with polished gradient aesthetics, supporting both dark and light themes. ✨

## Features

- **Dynamic URL Input** 🔗:
- Users can input the second part of a GCP storage URL, which is automatically appended to a base URL for previewing the content.

- **Base URL Settings** ⚙️:
- A modal allows users to change the base URL, with settings stored in local storage or state management for persistence.

- **Responsive Design** 📱💻:
- The UI is designed to be fully responsive, ensuring accessibility and usability on both mobile and desktop platforms.

- **Theme Support** 🌈:
- Supports both dark and light themes, utilizing CSS variables for easy theme switching and a consistent gradient look.

- **Media Preview** 🖼️📄🎬:
- Supports previewing various media types, including images, documents, and videos.
